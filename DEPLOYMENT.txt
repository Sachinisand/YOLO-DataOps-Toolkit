🎮 KEYBOARD CONTROLS
====================

DRAWING & SELECTION:
• Click & Drag    → Draw bounding box
• Right Click     → Select/deselect box
• 0-9             → Set class ID

EDITING:
• X               → Delete selected box
• C               → Clear all boxes
• U               → Undo
• Y               → Redo

ZOOM & NAVIGATION:
• +/-             → Zoom in/out
• Arrow Keys      → Pan image
• R               → Reset view

SAVING:
• Q               → Save and next image

📊 DATA FORMAT
==============

Output: YOLO Format (.txt files)
Format: <class_id> <x_center> <y_center> <width> <height>
Coordinates: Normalized (0-1 range)
Delimiter: Space

Example:
0 0.5234 0.3456 0.2341 0.4567
1 0.7234 0.6543 0.1567 0.2341

🚀 QUICK START
==============

1. Place images in: data/images/

2. Start annotation:
   python src/yolo_manager.py annotate --img_dir data/images --save_dir data/annotated_labels

3. View results:
   python src/yolo_manager.py visualize --img_dir data/images --lbl_dir data/annotated_labels --save_dir data/visualizations

4. Edit if needed:
   python src/yolo_manager.py review --img_dir data/images --lbl_dir data/annotated_labels --save_dir data/updated_labels
